# Stage C Landing Copy Variants (Trust + Clarity)

## Variant A — Calm + Practical (Selected)
Tone: grounded, clear, minimal hype.

- Hero promise: steady habits and daily groundedness.
- Core value: privacy-first, offline-first, focused daily flow.
- Feature framing: Today clarity, natural dhikr, quiet group accountability, reminders + insights.
- FAQ focus: pricing clarity, privacy, reminders, account optionality.

## Variant B — Devotional + Warm
Tone: warmer and more spiritually expressive while staying product-concrete.

- Hero promise: building consistent worship rhythms with calm support.
- Core value: thoughtful design that protects attention and intention.
- Feature framing: gentle rhythm, remembrance support, trusted circles.
- FAQ focus: adab in language, privacy confidence, reminder flexibility.

## Variant C — Performance + Outcomes
Tone: direct and outcome-driven.

- Hero promise: consistency outcomes over time.
- Core value: less friction, faster check-ins, higher follow-through.
- Feature framing: due-today filtering, measurable streak momentum, accountability loops.
- FAQ focus: retention levers, reminders, practical onboarding friction.

## Why Variant A was selected
- Best fit for Sunnad MVP positioning and existing product maturity.
- Strong trust signal without overclaiming.
- Maintains religious friendliness while improving conversion clarity.
